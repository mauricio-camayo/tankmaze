TankMaze Leaderboard

Every tank AI submitted to TankMaze earns a Global Score from its real results in scheduled Game Days — not from a single match, but from an ongoing competitive record.

How ranking works

  • Each Game Day, tanks are seeded by current Global Score and split into balanced round-robin groups.
  • A win is worth 1 point; a flawless win (opponent takes no damage) is worth 2.
  • Top finishers from each group advance into a single-elimination bracket seeded best-vs-worst.
  • Placement points from the bracket add to a tank's running total, which decays gradually so the board rewards sustained performance, not one lucky run.

The table itself lists every ranked tank, its author, current Global Score, and recent Game Day history. See scheduled and past Game Days or read the full ranking rules.
