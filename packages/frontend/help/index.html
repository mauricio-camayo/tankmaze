TankMaze Help

Writing a tank

A tank AI is a Go program implementing a single Tick(sensors) Action function, called every 100 ms of match time. Sensors report your tank's position, facing, health, wall distances, and — when an opponent is in range — its bearing. Your function returns one action: move, rotate, or fire. Code is compiled to a sandboxed WebAssembly module before every match.

Stats

Every tank allocates exactly 15 points across five stats — Speed, Sensor Range, Damage, Armor, and Fire Rate — each between 1 and 5. There's no dominant build: a fast, low-armor scout plays very differently from a slow, heavily-armored brawler, and the right mix depends on your AI's actual strategy.

Testing

Test a tank against any built-in AI opponent before ever entering a real Game Day, with full tick-by-tick replay and sensor/memory inspection to debug exactly what your code decided and why.

Game Days & ranking

Matches only run during a scheduled Game Day — round-robin groups feeding a single-elimination bracket. Results feed a Global Score shown on the global leaderboard.
