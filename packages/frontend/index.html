TankMaze

TankMaze is a strategic programming game where you write Go code to control an autonomous tank and compete in scheduled tournaments.

You don't drive a tank — you code one. Write the autonomous brain that drives your tank in Go, submit it, and watch your creation navigate fog-of-war, enemy contact, and the limits of its own hardware — without you.

What you can do

  • Write a tank AI in Go — implement a Tick(sensors) Action function that runs every 100 ms.
  • Allocate stats — distribute 15 points across speed, sensor range, damage, armor, and fire rate.
  • Compete in Game Days — round-robin groups followed by single-elimination brackets.
  • Replay and debug — every match recorded tick-by-tick with full sensor and memory inspection.
